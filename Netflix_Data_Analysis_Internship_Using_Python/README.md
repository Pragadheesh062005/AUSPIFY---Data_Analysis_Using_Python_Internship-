# Netflix Data Analysis Internship — Auspify

A professional, separate-notebook submission for all six tasks in the Auspify Data Analysis Using Python internship.

## Files
- `Dataset (1)(1).csv` — supplied source dataset.
- `Task_1_Data_Cleaning.ipynb` — data quality checks, cleaning, validation, and cleaned CSV export.
- `Task_2_Content_Type_Analysis.ipynb` — Movies vs TV Shows counts and charts.
- `Task_3_Country_Analysis.ipynb` — country ranking and content-type comparison.
- `Task_4_Release_Year_Trend.ipynb` — release-year trends and year-over-year differences.
- `Task_5_Rating_Genre_Analysis.ipynb` — ratings and genre analysis.
- `Task_6_Business_Insights_Report.ipynb` — EDA summary, dashboards, findings, and report guidance.
- `outputs/` — generated CSV summaries and chart images (created when notebooks run).

## How to run
1. Extract the ZIP file.
2. Install Jupyter Notebook and the dependencies in `requirements.txt`.
3. Open the project folder in Jupyter Notebook.
4. Run `Task_1_Data_Cleaning.ipynb` from top to bottom first.
5. Then run Tasks 2, 3, 4, 5, and 6 in order.
6. Check the `outputs/` folder for charts and summary CSVs.

## Important notes
- Each notebook is a separate task submission.
- Tasks 2–6 require the cleaned CSV generated by Task 1.
- Country counts can overlap because one title may be associated with multiple countries.
- Genre counts can overlap because one title can belong to multiple genres.
- This dataset describes catalogue metadata; it does not include viewership or revenue.
- Review all outputs and write findings based on the results generated by your run.
